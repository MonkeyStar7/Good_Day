# Good Day

Good Day 是一个以 Markdown 文件保存数据的 Windows 日计划应用。把长期目标、阶段计划和今天要做的事放在一起，数据始终保存在你自己的电脑上。

## 当前版本：1.3.2

当前版本将今日、计划、目标、事件和历史统一放到窗口左侧的彩色便签，去掉便签外围的系统透明边框和矩形阴影，让便签直接从主页面边缘伸出。窗口仍可拖动和缩放。屏幕中央使用独立提醒卡片；任务仍从今日列表的加号添加，展开后设置日期与重复；历史支持日期筛选和搜索。也包含 1.2.0 的事件提醒和 1.1.0 的保存、备份恢复、跨日刷新与防重复启动改进。

1.3.2 正式下载包包含此前内部审核的全部改进，使用正式数据目录，不需要开发环境。完整更新内容见 [1.3.2 更新说明](docs/release-1.3.2.md)；下方介绍日常使用、数据备份和升级方法。历史审核记录保留在 `docs/` 中供开发者参考。

后续更新按 `1.3.2 → 1.3.3 → … → 1.3.9 → 1.4.0` 递增，先完成 1.3 系列的调整，再升级到 1.4。

## 下载与启动

**[下载最新 Windows 版本](https://github.com/MonkeyStar7/Good_Day/releases/latest)**

当前版本：[1.3.2 Windows x64 便携包](https://github.com/MonkeyStar7/Good_Day/releases/download/v1.3.2/Good-Day-1.3.2-windows-x64.zip) · [SHA-256 校验文件](https://github.com/MonkeyStar7/Good_Day/releases/download/v1.3.2/Good-Day-1.3.2-windows-x64.zip.sha256)。

1. 在发行版的 **Assets** 中下载 `Good-Day-版本号-windows-x64.zip`。GitHub 的 `Source code` 和首页的 `Download ZIP` 是源码，不能直接运行。
2. 将 ZIP **完整解压**到一个可长期存放的位置，例如 `C:\Users\你的用户名\Apps\Good Day`。
3. 打开解压后的 `Good Day` 文件夹，双击 `good_day.exe`。可以为它创建桌面快捷方式。

发布包适用于 **Windows 10 / 11 的 Intel、AMD 64 位电脑（x64）**，无需安装 Flutter 或开发工具。包内包含 Visual C++ 运行库、插件和资源文件，请保留整个文件夹，不要只复制 `.exe`，也不要直接在压缩包里运行。ARM64 电脑未做验证。

当前版本未进行代码签名，Windows 可能显示来源提示。请核对下载来源和发行版附带的 SHA-256 校验文件；如果系统或组织策略阻止运行，请遵循设备管理要求。

## 功能介绍

| 功能 | 可以做什么 |
| --- | --- |
| 今日 | 添加、编辑和完成任务，查看当天完成数量 |
| 日期与历史 | 安排今天、明天或指定日期的任务，按日期查看和搜索历史 |
| 重复任务 | 每天、工作日、每周或每月生成独立记录，完成后安排下一次，可结束重复 |
| 子任务 | 将任务拆成小步骤，分别勾选完成 |
| 计划 | 管理带截止日期的计划，查看剩余时间并标记完成 |
| 目标 | 创建长期目标，设置说明和颜色，并关联任务或计划 |
| 待办事件 | 设置一次性或重复事件、事件日期时间和提前提醒，到点弹窗，支持稍后提醒与暂停 |
| 本地 Markdown | 自动保存任务、计划、目标和每日记录，关闭后可恢复 |
| 垃圾桶 | 查看和恢复从界面删除的任务、计划及目标 |
| 数据备份 | 每天首次读取或修改数据前自动备份，手动备份、校验和恢复，保留最近 7 份 |
| 外观设置 | 调整字体和强调色 |
| 桌面使用 | 托盘显示与隐藏、窗口缩放，以及可选的开机启动 |
| 数据文件夹 | 切换到已有 Vault，或将数据迁移到新的空文件夹 |

日常使用无需登录账号，也不需要连接云端服务。当前没有内置跨设备云同步或自动更新功能。

## 怎么使用

### 安排今天的任务

1. 打开应用，点击左侧 **今日** 便签。
2. 点击列表中的 **＋**，输入任务内容，按 Enter 保存。
3. 展开任务进行编辑、添加子任务，或关联目标。
4. 完成后勾选任务或子任务，顶部会更新完成数量。

### 任务日期、历史与重复

点击左侧 **今日** 便签，使用列表中的加号添加任务；展开任务后点击日期按钮，选择今天、明天或指定日期，并设置每天、工作日、每周或每月重复。默认“不重复”，不再提供重复的“安排任务”入口。已完成记录保留日期，需要新的日期请新建任务。

点击左侧 **历史** 便签，切换今天、明天、未来、历史或全部，选择具体日期，或者搜索任务、备注及子任务。单次任务未完成仍延续到今天，并保留最初安排日期；重复任务的过去未完成记录保留在历史中。

重复任务每次都是独立记录。完成本次会安排下一次，子任务内容和目标关联保留，新的子任务默认未完成。工作日指周一至周五；每月没有对应日号时安排在月末，下个月恢复原日号。退出数日后启动只补最近一次，避免堆积。

在历史页中展开任务，**删除本次**只删该条记录，**结束重复**停止后续生成并将未来未完成记录移入垃圾桶，今天与历史保留。修改日期或规则会结束原来的重复安排，创建新安排。任务日期安排不会自动设置弹窗提醒，需要提醒请在“事件”中设置。

### 管理计划和目标

点击左侧 **目标** 便签，添加目标名称、说明和颜色；再点击 **计划** 便签，创建计划并设置截止日期。任务和计划可以关联目标，方便把每天的行动和长期方向联系起来。

### 设置、托盘与退出

点击齿轮打开 **设置**，可更改字体、强调色、数据存放文件夹和开机启动选项。

点击窗口关闭按钮会隐藏到系统托盘，应用仍在运行。单击托盘图标可重新显示；右键托盘图标可以显示、隐藏、打开设置或选择 **退出 Good Day**。如果看不到图标，请查看任务栏的隐藏图标区域。

开启开机启动前，请先将程序放到固定位置；以后移动程序文件夹，需要重新开启开机启动。

### 待办事件与弹窗提醒

1. 点击左侧 **事件** 便签，再点击 **添加待办事件**，输入要做的事情及可选备注。
2. 选择事件日期和时间。重复方式可以选 **仅一次、每天、工作日、每周、每月**；每周按所选日期的星期重复，每月按所选日号重复，没有该日号的月份在月末提醒。工作日指周一至周五，不按法定节假日调整。
3. 设置提前多少分钟提醒：`0` 表示准时，也可点快捷选项或输入 0～10080 分钟。确认预览的提醒时间后，点击 **保存**。
4. 到点后，Good Day 会在所在显示器的整个屏幕中央显示暖白圆角的独立置顶提醒卡片，以浅绿时间区、大号时间和圆角按钮显示提醒，隐藏到托盘时主窗口也无需显示。点击 **知道了** 结束本次提醒，或选择 **5、10、30 分钟后**。一次性事件结束后自动关闭提醒，重复事件继续下一次。关闭提醒框或按 Esc 表示 5 分钟后再提醒；保存成功才关闭，失败可重试。
5. 事件列表中的开关可暂停提醒；点击编辑可修改时间、重复方式和提醒设置。删除进入垃圾桶，恢复后的事件默认暂停，请确认时间后重新启用。

**运行方式：**关闭窗口只是隐藏到托盘，提醒仍运行，通常在设定时间后 5 秒内检查；彻底退出、关机或休眠期间不能弹窗，启动或唤醒后补最近一次错过的提醒。正在设置、确认删除或编辑事件时，先完成或取消当前操作，再弹出提醒。已保存的稍后提醒在重启后保留。可以在设置中开启开机启动。

提醒使用电脑当前的本地时间。恢复备份会同时还原提醒记录，旧提醒可能再次出现。提醒确认属于“这次已提醒”，不会自动完成“今日”里的任务。

### 删除与恢复

从界面删除的内容会进入垃圾桶。打开 **设置 → 垃圾桶**，选择需要恢复的内容。

## 数据存放与备份

首次启动会在当前用户的 **文档**目录创建 `Good Day Vault`。实际路径可在 **设置 → 存放文件夹**中查看，文档目录被 OneDrive 等服务重定向时，以设置中的路径为准。

```text
Good Day Vault/
├── Tasks/       # 任务与子任务
├── Plans/       # 带截止日期的计划
├── Goals/       # 长期目标
├── Events/      # 待办事件、重复规则和提醒状态（1.2.0）
├── TaskSeries/  # 重复任务模板与生成进度（1.3.0）
├── Daily/       # 每日计划与完成记录
└── Archive/     # 垃圾桶中的内容
```

这些 Markdown 文件是应用的数据源。可以使用 Obsidian、VS Code 等工具查看；外部编辑后，重新打开 Good Day 读取修改。请保留文件中的元数据和结构。Daily 文件中 `goodday:begin` 与 `goodday:end` 之间由应用维护，标记外可以自由书写。

Events 的日程和提醒状态保存在文件头的 `goodday-event` 元数据中；正文用于阅读，修改事件请使用应用中的编辑入口。

**自动和手动备份：**每天首次读取或修改数据前自动备份，保留最近 7 份。打开 **设置 → 数据备份**，可以立即备份、查看备份列表、校验并恢复。恢复前会再备份当前数据。备份存放在当前 Vault 内，不能替代存放在其他磁盘上的备份。

**换电脑或保留独立备份：**先从托盘退出应用，再复制整个 Vault 文件夹（包括其中的设置文件和隐藏的 `.goodday` 目录）到备份位置。便携包仅包含程序，不包含开发者的个人任务数据。

**迁移：**在设置中更改存放文件夹。选择空文件夹会迁移现有数据，默认保留原位置；选择已有 Vault 会切换到其中的数据。勾选“迁移后删除原数据”会在确认后删除原位置受应用管理的数据，请先备份。

## 更新与卸载

- **更新：**先在设置中查看并备份现有 Vault，再从托盘退出应用，下载新版并完整解压到原程序位置，覆盖程序文件。Vault 保存在独立的数据目录中，不要用程序包覆盖或删除 Vault。启动后确认数据存放文件夹正确；若使用自定义位置，可在设置中选择原来的 Vault。1.0.0 用户也可以按此步骤直接升级到 1.3.2。当前需要手动下载更新。
- **卸载：**先关闭设置中的开机启动，再从托盘退出，删除程序文件夹和快捷方式。Vault 会保留；仅在确认不再需要数据后才手动删除它。

## 常见问题

- **下载后找不到程序：**确认下载的是发行版 Assets 中的 Windows ZIP，而不是 Source code。
- **提示缺少 DLL：**重新完整解压发布包，保留 `.exe`、所有 `.dll`、`app_icon.ico` 和 `data` 文件夹。如果仍缺少 Visual C++ 运行库，可安装 [微软官方 x64 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)。
- **关闭窗口后仍在运行：**这是托盘行为，右键托盘图标选择“退出 Good Day”可完全退出。
- **换电脑后没有原来的任务：**任务保存在本地，需要复制备份的 Vault，并在新电脑的设置中选择该文件夹。
- **问题反馈：**请到 [GitHub Issues](https://github.com/MonkeyStar7/Good_Day/issues) 提供版本号、Windows 版本及复现步骤，分享截图前请隐藏个人任务内容。

## 本地开发与打包

开发需要 Flutter（Dart SDK 3.13.2 或兼容版本）和 Visual Studio 的“使用 C++ 的桌面开发”组件。

```powershell
flutter pub get
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
flutter run -d windows
```

生成包含 Visual C++ 运行库、使用说明和 SHA-256 校验文件的 Windows 便携包：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package-windows.ps1
```

脚本会重新构建 Release 版本；产物位于 `build/releases/`。版本号读取自 `pubspec.yaml`，发布时将 ZIP 和对应的 `.sha256` 文件上传到 GitHub Releases。

仅制作使用独立数据的内部试用包（不会上传或更新已安装应用）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package-windows.ps1 -InternalReview
```
