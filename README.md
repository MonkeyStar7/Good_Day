# Good Day

Good Day 是一个以 Markdown 文件保存数据的 Windows 日计划应用。把长期目标、阶段计划和今天要做的事放在一起，数据始终保存在你自己的电脑上。

## 下载与启动

**[下载最新 Windows 版本](https://github.com/MonkeyStar7/Good_Day/releases/latest)**

1. 在发行版的 **Assets** 中下载 `Good-Day-版本号-windows-x64.zip`。GitHub 的 `Source code` 和首页的 `Download ZIP` 是源码，不能直接运行。
2. 将 ZIP **完整解压**到一个可长期存放的位置，例如 `C:\Users\你的用户名\Apps\Good Day`。
3. 打开解压后的 `Good Day` 文件夹，双击 `good_day.exe`。可以为它创建桌面快捷方式。

发布包适用于 **Windows 10 / 11 的 Intel、AMD 64 位电脑（x64）**，无需安装 Flutter 或开发工具。包内包含 Visual C++ 运行库、插件和资源文件，请保留整个文件夹，不要只复制 `.exe`，也不要直接在压缩包里运行。ARM64 电脑未做验证。

当前版本未进行代码签名，Windows 可能显示来源提示。请核对下载来源和发行版附带的 SHA-256 校验文件；如果系统或组织策略阻止运行，请遵循设备管理要求。

## 功能介绍

| 功能 | 可以做什么 |
| --- | --- |
| 今日 | 添加、编辑和完成任务，查看当天完成数量 |
| 子任务 | 将任务拆成小步骤，分别勾选完成 |
| 计划 | 管理带截止日期的计划，查看剩余时间并标记完成 |
| 目标 | 创建长期目标，设置说明和颜色，并关联任务或计划 |
| 本地 Markdown | 自动保存任务、计划、目标和每日记录，关闭后可恢复 |
| 垃圾桶 | 查看和恢复从界面删除的任务、计划及目标 |
| 外观设置 | 调整字体和强调色 |
| 桌面使用 | 托盘显示与隐藏、窗口缩放，以及可选的开机启动 |
| 数据文件夹 | 切换到已有 Vault，或将数据迁移到新的空文件夹 |

日常使用无需登录账号，也不需要连接云端服务。当前没有内置跨设备云同步或自动更新功能。

## 怎么使用

### 安排今天的任务

1. 打开应用，在顶部选择 **今日**。
2. 点击列表中的 **＋**，输入任务内容，按 Enter 保存。
3. 展开任务进行编辑、添加子任务，或关联目标。
4. 完成后勾选任务或子任务，顶部会更新完成数量。

### 管理计划和目标

在顶部选择 **目标**，添加目标名称、说明和颜色；再切换到 **计划**，创建计划并设置截止日期。任务和计划可以关联目标，方便把每天的行动和长期方向联系起来。

### 设置、托盘与退出

点击齿轮打开 **设置**，可更改字体、强调色、数据存放文件夹和开机启动选项。

点击窗口关闭按钮会隐藏到系统托盘，应用仍在运行。单击托盘图标可重新显示；右键托盘图标可以显示、隐藏、打开设置或选择 **退出 Good Day**。如果看不到图标，请查看任务栏的隐藏图标区域。

开启开机启动前，请先将程序放到固定位置；以后移动程序文件夹，需要重新开启开机启动。

### 删除与恢复

从界面删除的内容会进入垃圾桶。打开 **设置 → 垃圾桶**，选择需要恢复的内容。

## 数据存放与备份

首次启动会在当前用户的 **文档**目录创建 `Good Day Vault`。实际路径可在 **设置 → 存放文件夹**中查看，文档目录被 OneDrive 等服务重定向时，以设置中的路径为准。

```text
Good Day Vault/
├── Tasks/       # 任务与子任务
├── Plans/       # 带截止日期的计划
├── Goals/       # 长期目标
├── Daily/       # 每日计划与完成记录
└── Archive/     # 垃圾桶中的内容
```

这些 Markdown 文件是应用的数据源。可以使用 Obsidian、VS Code 等工具查看；外部编辑后，重新打开 Good Day 读取修改。请保留文件中的元数据和结构。Daily 文件中 `goodday:begin` 与 `goodday:end` 之间由应用维护，标记外可以自由书写。

**备份：**先从托盘退出应用，再复制整个 Vault 文件夹（包括其中的设置文件）到备份位置。便携包仅包含程序，不包含开发者的个人任务数据。

**迁移：**在设置中更改存放文件夹。选择空文件夹会迁移现有数据，默认保留原位置；选择已有 Vault 会切换到其中的数据。勾选“迁移后删除原数据”会在确认后删除原位置受应用管理的数据，请先备份。

## 更新与卸载

- **更新：**从托盘退出应用，下载新版并完整解压到原程序位置，覆盖程序文件。Vault 保存在独立的数据目录中。当前需要手动下载更新。
- **卸载：**先关闭设置中的开机启动，再从托盘退出，删除程序文件夹和快捷方式。Vault 会保留；仅在确认不再需要数据后才手动删除它。

## 常见问题

- **下载后找不到程序：**确认下载的是发行版 Assets 中的 Windows ZIP，而不是 Source code。
- **提示缺少 DLL：**重新完整解压发布包，保留 `.exe`、所有 `.dll`、`app_icon.ico` 和 `data` 文件夹。如果仍缺少 Visual C++ 运行库，可安装 [微软官方 x64 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)。
- **关闭窗口后仍在运行：**这是托盘行为，右键托盘图标选择“退出 Good Day”可完全退出。
- **换电脑后没有原来的任务：**任务保存在本地，需要复制备份的 Vault，并在新电脑的设置中选择该文件夹。
- **问题反馈：**请到 [GitHub Issues](https://github.com/MonkeyStar7/Good_Day/issues) 提供版本号、Windows 版本及复现步骤，分享截图前请隐藏个人任务内容。

## 本地开发与打包

开发需要 Flutter（Dart SDK 3.13.2 或兼容版本）和 Visual Studio 的“使用 C++ 的桌面开发”组件。

```powershell
flutter pub get
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
flutter run -d windows
```

生成包含 Visual C++ 运行库、使用说明和 SHA-256 校验文件的 Windows 便携包：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package-windows.ps1
```

脚本会重新构建 Release 版本；产物位于 `build/releases/`。版本号读取自 `pubspec.yaml`，发布时将 ZIP 和对应的 `.sha256` 文件上传到 GitHub Releases。
