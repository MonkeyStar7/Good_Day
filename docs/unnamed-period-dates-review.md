# 1.3.8 本机试用说明

本版只在本地提交和安装，尚未上传 GitHub；公开下载包仍为 1.3.2。沿用 E:\Apps\Good Day 安装目录和原数据目录。

## 改进

- 清空待办任务主名称或只填写空格，保存时自动生成“未命名1、未命名2……”，不再显示“任务内容不能为空”，也不阻止收起、切换页面或关闭窗口。
- 自动编号检查当前任务、完成记录、垃圾桶与重复任务模板，避免与已有默认名称重复。已使用默认名称的任务再次清空时保留原编号。
- 添加任务时直接按 Enter 提交空名称，也会生成默认名称；打开空白添加框后直接离开仍取消空草稿。
- 保存期间继续输入新名称，不会被刚生成的默认名称覆盖。
- 今日：显示具体年月日与星期；本周：显示 ISO 周数以及周一至周日的范围，跨年范围注明年份；本月：显示年月；本年：显示年份。
- 周期日期沿用跨日刷新，软件后台运行或重新打开时会更新。
- 今日未完成任务在当天结束后进入待安排，不自动挪到次日；已完成任务保留完成状态和完成日期，在历史及较大的周期汇总中查看，不进入待安排。

## 检查

1. 展开一个任务，清空主名称，等待保存或直接切换页面；检查自动名称和保存成功，备注保留。
2. 再清空另一个任务，检查默认名称编号递增。重新打开应用确认名称仍在。
3. 在今日、本周、本月、本年间切换，检查具体日期范围。
4. 将一个今日任务完成、另一个保留未完成。到第二天后检查前者仍已完成并可在历史、本周找到，后者只进入待安排。
5. 在 340 与 400 宽度查看日期栏，检查长周范围能完整显示。

测试覆盖空名称持久化、并发编号、保存过程中新输入保护、跨年周数、跨日日期刷新与完成状态保留。

验证结果：133 项自动测试通过，静态分析无问题，Windows Release 构建成功；340 与 400 宽度的日期栏及提醒面板预览检查通过，打包脚本语法检查通过。
