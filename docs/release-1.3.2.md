# Good Day 1.3.2

这是从 GitHub 1.0.0 下载版到 1.3.2 的完整更新，包含此前在本机审核的可靠性、日程和界面改进。版本继续在 1.3 系列内递增，完成 1.3.9 后再升到 1.4.0。

## 更新内容

- 左侧彩色便签统一切换今日、计划、目标、事件和历史。去掉外围透明系统边框和矩形阴影，仍可拖动和缩放。
- 任务可设置今天、明天或指定日期。历史支持日期筛选与搜索，单次任务顺延保留最初安排日期。
- 重复任务支持每天、工作日、每周、每月，每次保留独立记录，可删除本次或结束重复。
- 待办事件支持一次性或重复提醒、提前提醒、暂停，以及 5 / 10 / 30 分钟后再次提醒。
- 提醒在整个显示器中央使用独立置顶卡片；应用隐藏到托盘后仍可提醒，彻底退出或关机后在下一次运行补最近一次。
- 编辑内容在切换页面和隐藏窗口前保存；保存失败保留编辑内容并允许重试。文件采用原子替换，写入按顺序处理。
- 每天首次读取或修改数据前自动备份，保留最近 7 份，支持手动备份、校验和恢复；恢复前备份当前数据。
- 防止相同程序重复启动及多个程序同时占用同一 Vault，支持跨日、唤醒和系统时间变化后刷新。

任务日期不等同于弹窗提醒；需要弹窗请在“事件”中设置。工作日指周一至周五，不处理法定节假日。每月缺少指定日号时使用月末。

## 下载和升级

下载发行版中的 `Good-Day-1.3.2-windows-x64.zip`，完整解压后打开 `Good Day/good_day.exe`。支持 Windows 10 / 11 x64，包内含 Visual C++ 运行库、插件和使用说明，无需安装 Flutter。

已有用户先备份 Vault，再从托盘退出应用，完整解压新版到原程序位置并覆盖程序文件。不要覆盖或删除数据目录。启动后在设置中核对数据位置；使用自定义目录时可选择原来的 Vault。程序包不包含个人任务数据。

发行版同时提供 `.sha256` 校验文件。程序目前没有代码签名或自动更新，需手动下载升级；ARM64 未做验证。
