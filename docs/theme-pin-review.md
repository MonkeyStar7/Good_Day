# Good Day 1.3.6 本机试用说明

版本：1.3.6+10。本机代码完成更新，尚未推送或发布到 GitHub；公开下载包仍为 1.3.2。

## 改进内容

- 历史展开记录不再显示重复和提醒设置。仍可搜索、查看备注及子任务、修改完成状态、删除本次或结束原来的重复任务。
- 强调色同时作用于主页面、左侧便签、展开面板、文字、分隔线、设置、历史、垃圾桶、提醒滚轮和独立提醒框。目标的颜色标签和错误提示保留各自含义。
- 右上角设置旁新增置顶钉子。点击后显示实心钉子及背景，窗口保持在前方；再次点击取消。设置与其他页面显示同一状态。置顶仅在本次运行中保留，下次启动默认关闭；弹窗提醒不会取消用户开启的置顶。
- 今日、本周、本月、本年、待安排改为无边框文字入口。当前项字体更大，其余较小，鼠标悬停有浅色反馈。待办页不再重复显示标题、日期和星期。
- 提醒开关前始终显示“提醒我”，由开关表示启用状态；已保存时间另外显示。
- 没有完成记录时隐藏整个已完成区。进行中为空时直接显示“＋ 添加待办任务”，已完成区和进行中之间留出空间，不增加空白任务行。

## 检查步骤

1. 在设置中切换四种强调色，检查主背景、便签、分隔线、展开任务和历史一起变化，目标名称仍保持目标颜色。
2. 点击钉子，再打开其他软件窗口，检查 Good Day 保持在前方；取消钉子后检查可被覆盖。在设置页确认状态保持一致。
3. 切换今日、本周、本月、本年、待安排，检查字号、悬停反馈与任务范围。
4. 在没有进行中任务的页面点击“添加待办任务”，完成后检查已完成区的位置；没有完成记录时不显示该区。
5. 展开历史记录，检查没有重复和提醒设置；搜索、完成状态和删除仍可使用。
6. 展开任务提醒，检查“提醒我”在关闭与启用时文字不变；自定义时间仍以当前系统时间为起点，鼠标滚动每次只移动一格。

沿用原安装目录 E:\Apps\Good Day 和原数据目录；更新前备份数据，就地替换程序，临时程序回退目录会在成功后清理。

验证：112 项自动测试通过，静态分析无问题，Windows Release 构建成功，独立提醒框居中测试通过；已检查 340 与 400 宽度以及绿色、蓝灰、暖棕主题预览。
