# Good Day 1.4.2 本机试用

本版仅本地提交、打包与原目录安装，不上传 GitHub。

- 新建或点击已有事项直接展开，备注下面就能添加子任务，已有事项立即显示右侧删除键。
- 完成、取消按钮按 2:1 分配宽度，仍保留保存失败时的草稿和托盘保存检查。
- 今天和计划取消添加加号，空分区点击标题横行即可添加，标题下面紧贴横线。已有事项下方保留空输入位，用虚线圆圈表示下一条事项。
- 添加子任务使用文字入口；计划右上角改用日期图标选择其他日期。
- 新增默认主题“云朵黄”，背景很浅，文字和按钮使用较深暖色。主题色块显示浅黄颜色；主面板、弹窗、日期选择与原生提醒一起配色。
- 已有用户明确选择的配色继续保留，可在设置中切换。此次本机试用切换到云朵黄，字体保持原选择。

所有已有事项、子任务、目标、历史、备份与垃圾桶继续保留；此前的过期提醒处理、日期重复规则和已完成样式不变。

试用重点：点击空分区最右侧空白、点击虚线圆圈添加下一条；直接编辑已有事项并删除；新建时直接添加子任务；缩窄窗口后确认按钮与弹窗完整显示；切换云朵黄与其他颜色。

验证结果：159 项完整自动测试通过，静态分析、格式检查与原生居中提醒测试通过；340 和 400 宽度实际界面预览已检查。
