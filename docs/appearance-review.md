# 1.4.6 本机试用

在设置 → 外观中选择界面大小：小 75%、中 100%、大 150%。文字、图标、按钮、间距、输入区和弹窗一起缩放；默认保持 100%，选择会随外观设置保存。

主题颜色新增“白色”，可搭配毛玻璃背景。默认主题仍为松绿，已有主题选择保留。透明度滑块范围为 0%～75%，默认 22%；数值越大，背景越通透，文字和图标保持清晰。

主界面使用 Windows 系统毛玻璃。独立提醒窗跟随缩放与背景透明度，系统不支持模糊时保留可读背景。较大的界面会提高窗口最小尺寸，避免按钮被挤出界面。

本版只在本机打包、安装，不向 GitHub 上传代码、标签或安装包。安装结构仍为 Good Day/App 和 Good Day/MD，升级沿用当前数据位置。
