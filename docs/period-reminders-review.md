# 1.3.7 本机试用说明

本版先用于本机审核，公开下载包仍为 1.3.2。安装时沿用原目录和数据，不改变已有任务、目标、计划与快捷方式。

## 界面

- 待办周期导航下增加柔和横线。文字共用下边缘，选中项向上放大并自然推开相邻项。
- 主题色增加至 10 种，目标色增加至 12 种；色盘使用圆形，选中项变大。
- 待办、计划主名称加大加粗。添加入口显示当前周期名称。
- 本周、本月、本年的已完成任务显示日、周、月、年来源；今日不显示来源。
- 历史显示任务周期和实际完成日期。

## 提醒

- 今日：快捷选 5 分钟、半小时、1 小时后；自定义滚轮选择从现在开始的小时数、分钟数，不选择年月日。
- 本周：选择本周周一至周日及那天的时间，过去的日期不能选。
- 本月：选择本月的日号及时间。
- 本年：选择本年的月份、日号及时间，天数随月份调整。
- 提醒只能设置在任务当前周期内的未来时间；待安排中的任务应先重新安排。
- 可选择只提醒一次，或未完成时按间隔继续提醒。支持分钟、小时，周／月／年还支持天；间隔必须小于该周期长度。
- 点击“知道了”处理本轮提醒，不关闭后续重复提醒。完成任务、关闭提醒或当前周期结束后停止。
- 提醒间隔和处理进度保存在原 Markdown 记录中，重启仍生效；错过多轮时只补一次，避免连续弹窗。
- 每天／每周等任务重复决定下一条任务何时生成，与同一条任务的重复提醒相互独立。
- 月末选择 31 日，二月按实际天数调整，之后恢复原日号；编辑标题和备注不会丢失原日号。

## 审核步骤

1. 切换五个待办周期，观察横线、文字向上放大及各周期添加入口。
2. 在设置和目标编辑区切换各色圆点，检查选中尺寸及整体配色。
3. 完成今日任务，在本周查看“日”来源；在历史查看完成日期与日待办类型。
4. 分别为日、周、月、年任务设置提醒，检查日期选择范围与滚轮逐项切换。
5. 设置几分钟间隔的重复提醒，点击“知道了”，等待下一轮；完成任务后确认不再提醒。
6. 重启应用检查提醒仍在；结束周期后确认停止并进入待安排。

自动检查覆盖提醒保存、重启、补提醒、完成与暂停、周期边界、月末恢复和窄窗口布局。图像预览检查导航、色盘、提醒滚轮布局。桌面安装后检查版本、单实例、窗口边框、原数据目录和文件保留。

本版验证结果：127 项 Flutter 测试通过，静态分析无问题，Windows Release 构建成功，原生居中提醒测试通过；已检查 340 与 400 宽度的导航、色盘及日／周／月／年提醒预览。
