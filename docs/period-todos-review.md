# Good Day 1.3.5 内部审核

只在本机开发、提交、打包和安装，等待内部试用；不推送 GitHub，不创建发行版。GitHub 正式版仍是 1.3.2。

## 提醒修复

- 开启提醒后，“提醒我”保持正常字体颜色。
- 每次展开“自定义时间”，重新读取系统当天日期和当前时分。未保存的滚轮调整在收起后放弃，再展开重新从当前时间开始。
- 关闭滚轮的旧位置缓存，避免重新打开时跳到 2000 年或上次未保存的位置。
- 鼠标滚轮每个滚动事件只移动一格，不因一次滚动幅度大而跳过多个数字；拖动、点击上下数字也能逐格调整。滚到边界不带动外层页面。
- 提醒保存失败保留当前输入供重试；确认提醒不会完成任务。

## 周期待办

- 顶部切换今日、本周、本月、本年、待安排。
- 自然周从周一到周日，月份和年份按系统当前日历切换。
- 在各周期页添加任务，进行中的任务只显示在对应周期页。各页上半部分是进行中，下半部分是已完成，完成后移到下方并显示删除线。
- 按实际完成日期汇总：今日任务完成后出现在对应本周、本月、本年的已完成；本周任务完成后出现在对应本月、本年；本月任务完成后出现在对应本年。更大的周期任务不会逆向进入小周期。
- 日、周、月、年过期后，已完成记录从当前周期视图退出，原数据和历史仍保留。
- 过期未完成的任务进入待安排，保留原任务、备注、子任务和目标。展开后选择重新安排到今日、本周、本月或本年。不会自动顺延，也不会删除记录。
- 旧版自动顺延的未完成普通任务使用保存的最初安排日期进入待安排；未修改的旧文件保持原样。旧版没有周期字段的任务按今日任务识别。
- 重新安排保留最初安排日期。重复任务后续按新周期生成，已有已完成记录保留；旧组已生成的未来未完成记录会按原有结束重复规则移入垃圾桶。未到时间的提醒保留原时间；过期提醒按当天原钟点重新安排，钟点已过去则暂停，可重新设置未来时间。

## 试用步骤

1. 展开待办开启提醒，检查“提醒我”字体没有变灰。
2. 展开自定义时间，核对系统当前日期和时分。调整滚轮后收起、再次展开，确认重新显示当前时间；鼠标滚动一格应只改变一个数字。
3. 在今日添加“刷三套卷子”，本周添加“刷完一整本”，确认两者进行中独立显示。
4. 完成今日任务，检查今日、本周、本月、本年的已完成；完成本周任务，检查本月、本年。
5. 打开待安排，展开旧记录重新安排到本周，确认原名称、备注、子任务仍在。
6. 检查历史中旧完成记录仍可搜索；原独立提醒仍可从设置管理。
