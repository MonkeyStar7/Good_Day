# Good Day 1.4.13 内部试用

- 待办重复独立于提醒开关，可选每天、工作日、周末、每周、每两周、每月、每三个月、每六个月、每年及自定义。
- 各日期独立记录完成情况；昨天未完成不会阻止今天出现新待办。新一条的子任务重新开始。
- 计划按日期显示未来重复待办。未来条目先预览，进入对应日期或编辑时才保存，避免无意义的数据膨胀。
- 名称与备注修改沿用到后续重复；修改日期或重复规则会重排后续未完成条目；关闭重复或删除重复待办会停止后续生成，过去记录保留。
- 设置提醒中保留日期、时间与提前提醒；“未完成时再次提醒”默认关闭，可设 1～720 分钟，完成、关闭提醒或当前日期结束后停止。
- 每次启动检查 GitHub 正式版，设置 → 软件更新可以手动检查并下载更新。只接受更新版本和官方仓库安装包，校验大小与 SHA-256 后执行安装。
- 使用安装版时，点击更新会保存当前编辑、退出、覆盖安装原 App 并重新打开；MD、设置、备份及自定义数据位置保留。未处理弹窗、未确认设置或保存失败会阻止安装。
- 不支持降级及预发布更新；便携版需要先使用安装包安装。下载失败可以重试，不修改程序和数据。
- 旧版 1.4.11 没有应用内更新按钮，需要手动安装一次本版后才能使用后续应用内更新。正式版本与下载入口见 README。
