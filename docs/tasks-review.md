# Good Day 1.3.0 本地审核

这是 1.3.0 的原始功能与审核记录；1.3.1 的左侧便签和新提醒外观见 [最新界面说明](navigation-review.md)，旧界面入口已替换。

本次加入任务日期与历史、重复任务，以及独立的屏幕中央提醒窗口。先在本机审核，尚未发布到 GitHub。

## 任务日期与历史

- **今日 → 安排任务**：填写名称、备注，选择今天、明天或指定日期，保存。
- 展开已有任务，点击日期按钮，可以重新安排日期和重复方式。已完成记录保留日期，只能修改名称和备注。
- **今日 → 日期与历史**：切换今天、明天、未来、历史或全部；按日期查看，或搜索名称、备注及子任务。
- 单次任务未完成仍按原有行为延续到今天，同时保存最初安排日期；历史中可查看已完成任务与过去未完成的重复任务。

## 重复任务

- 支持每天、工作日（周一至周五）、每周、每月；不重复是默认选项。
- 每次独立记录，完成本次会安排下一次。子任务内容和目标关联会保留，新一次的子任务恢复未完成。
- 工作日不处理法定节假日；每周按起始星期，每月缺少该日号时安排在月末，下个月恢复原日号。
- 跨日自动生成应做的任务；退出数日后启动，只补最近一次，不堆积错过的每一天。以前生成但未完成的记录仍保留原日期，可在历史中查看。
- 在“日期与历史”展开任务：**删除本次**只删该条，**结束重复**停止生成并将未来未完成记录移入垃圾桶，今天和历史保留。
- 修改日期或重复方式会结束原规则并开启新安排；修改未完成任务的名称、备注、目标或子任务影响以后新生成的任务。已生成记录保留各自状态。

## 独立提醒窗口

- 事件到点后，在 Good Day 所在显示器的整个屏幕中央弹出独立窗口，置顶显示大号事件名称、时间和备注。
- 主程序隐藏到托盘也能提醒；主窗口不必弹回右侧。提醒处理期间暂时禁止操作主窗口。
- **知道了**确认本次，**5 / 10 / 30 分钟后**稍后提醒；关闭提醒窗口或按 Esc 等同于 5 分钟后再提醒。
- 先保存确认或稍后提醒状态再关闭；保存失败保留窗口并允许重试。
- 完全退出或关机后不能弹窗，下次启动补提醒；重复事件与重复任务分别管理，确认提醒不会自动完成任务。

## 建议试用

1. 安排明天的一次性任务，确认今日没有、明天列表有。
2. 创建每日重复任务并添加子任务，完成后确认明天出现一条新记录、子任务未勾选。
3. 在历史中搜索刚完成的任务；按日期查找，并检查原记录仍在。
4. 结束一组重复任务，确认未来记录进垃圾桶、已完成记录保留。
5. 创建两分钟后的事件，隐藏到托盘，确认屏幕中央出现独立提醒；选择 5 分钟后再提醒，再试“知道了”。

## 验证记录

自动化验证覆盖日期安排、原日期保留、独立重复记录、并发刷新防重复、重启补最近一次、删除不重建、停止重复、月底规则、保存失败回滚，以及备份与迁移。

界面验证覆盖 340 / 400 像素窗口下的编辑、日期选择、搜索、历史筛选和失败重试。Windows 原生测试验证独立窗口的屏幕中心坐标、置顶、隐藏主窗口、按钮动作和保存前不关闭。

原生测试（先完成 Windows Release 构建）：

```powershell
cmake -S test/windows -B build/native-tests -G "Visual Studio 17 2022" -A x64
cmake --build build/native-tests --config Release
ctest --test-dir build/native-tests -C Release --output-on-failure
```
