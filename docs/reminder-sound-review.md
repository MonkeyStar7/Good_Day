# 1.4.12 本机试用

置顶时，背景窗口切换、移动、最小化、隐藏或关闭会触发毛玻璃背景更新；窗口动画结束后再刷新一次。更新不会激活 Good Day，托盘隐藏或最小化时不重绘，也不进行持续轮询。

设置 → 桌面 → 提醒声音可选择轻巧木音、柔和双音、清亮铃声、温暖琴音或静音，并可试听。默认使用轻巧木音。提醒弹窗真正出现时播放一次短音，不循环；已打开的同一提醒不重复播放。

四段音效为 Good Day 自行合成，生成程序为 `scripts/generate-reminder-sounds.py`，不使用外部录音。音效以短 PCM WAV 文件随安装包和免安装包打包，无需联网播放。

保留 Good Day/App 和 Good Day/MD 的安装结构；升级沿用原数据和外观设置。此版本只在本机打包、安装，尚未发布到 GitHub。
