# Good Day 1.4.1 本机试用

本版仅本地提交、打包和安装，不推送 GitHub。沿用 `E:\Apps\Good Day` 与现有数据目录，升级前先保存和备份，再就地替换程序。

## 使用变化

- 今天按上午、下午、今晚分区，空白处仅保留横线和小加号。点击后直接在圆圈后填写名称、备注，不弹出整个事项编辑窗口。
- “提醒我”开关就在输入行下面。默认关闭，普通待办无需填写提醒设置；开启后弹出小窗口，设置日期、逐项滚轮时间、重复和提前提醒。上午、下午、今晚默认时间为 09:00、15:00、20:00。
- 设置完后显示简洁摘要，点击摘要重新编辑。弹窗内容可滚动，完成按钮固定可见；日期和下拉选项使用当前主题颜色与圆角。
- 小箭头展开所属目标和子任务。收起后备注、子任务及勾选状态仍显示。展开现有事项时，右边的小垃圾桶直接移入垃圾桶，可从设置恢复。
- 新建或修改时，已经过去的提醒时间只标红，不立即弹窗。此前设置的未来提醒若因关机错过，重启后仍会补提醒。
- 计划显示今天、明天、后天和本周剩余日期；本月其他日期折叠，可展开逐日添加。后续十二个月只列有事项的日期，空月份仅显示月份标题，点击默认该月 1 日 09:00，支持继续增加月份。
- 事项标题更深、加粗；分组标题颜色更浅；主面板四个角统一圆角。已完成项仍沿用原来的计数、显示／隐藏和删除线。

## 数据保留

已有 1.4.0 事项直接继续使用，无子任务的旧文件仍可读取。新增子任务保存在同一条 Markdown 记录内，备份、恢复、垃圾桶、历史一起保留。完成重复事项后，下一次保留子任务名称，并重置勾选状态；本次的原勾选状态留在历史中。

## 试用检查

1. 点击空行，只输入名称、备注，保存后确认内容仍显示；展开并添加子任务，收起后勾选子任务。
2. 开启提醒，查看各分区默认时间，设置自定义重复与提前提醒；保存、重新打开、重启后核对。
3. 设置已经过去的时间，确认标红且不立即提醒；设置未来时间，确认正常提醒。
4. 查看本周完整日期、展开本月其他时间、点击空月份，核对默认日期为当月 1 日 09:00。
5. 展开现有事项，点击右侧垃圾桶，再从设置恢复；核对备注和子任务仍在。
6. 切换主题，查看提醒弹窗、日期选择与按钮风格；缩窄窗口，确认设置仍可滚动、保存按钮可见。

发布到 GitHub 仍需用户另行明确要求。

验证结果：159 项完整自动测试通过，静态分析无问题；340 与 400 宽度界面、提醒设置滚动、直接删除、取消设置、子任务保存、重复生成和备份恢复均有验收覆盖。
