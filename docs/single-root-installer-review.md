# 单主目录安装：本机试用

只选择一次主目录，安装包统一使用以下名称，不随 Windows 系统语言改变：

```text
Good Day/
├── App/   程序和运行库
└── MD/    首次安装的 Markdown 数据、设置和备份
```

选择一个上级文件夹时，安装包会补上 `Good Day`；已经选择 `Good Day` 时不会再套一层。默认主目录仍在当前用户的 `AppData\Local\Programs\Good Day`，数据页不再单独出现。

升级读取当前保存的数据位置，已有用户主动迁移过的数据继续沿用，不自动覆盖其选择。旧版程序在主目录内的情况会迁入 `App`，只清理明确列出的旧运行文件，不删除用户 Markdown。卸载仅移除程序，保留 `MD` 和目录配置。

运行保护同时检查旧、新两个程序位置。旧的开机启动入口随程序位置更新，不为未启用开机启动的用户自动开启。

本机沿用 `E:\Apps\Good Day` 主目录。现有数据先备份，再复制验证到其 `MD` 子目录；确认后才切换配置，原数据目录保留作为数据备份。

程序体积主要来自 Flutter 图形引擎、编译后的界面与程序库、字体和 Windows 运行库，与待办功能的数量并不成比例。本版修改安装结构，未更换技术框架。

本版暂不上传 GitHub，公开版本仍为 1.4.4。
