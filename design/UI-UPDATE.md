# Good Day · Quiet Paper UI

2026-09-12：将已确认的视觉方向直接实现到 Flutter。用户确认不需要 Figma 文件，因此本次不交付 Figma 插件，也不要求安装额外设计软件。

## 已实现

- 96% 不透明暖纸白背景、方角、细分隔线、统一字号与低饱和配色。
- 44px 轻量标题栏，保留原品牌图标，设置齿轮改为细线轮廓。
- 今日 / 计划 / 目标可以直接点击切换，仍支持点击大标题循环切换；分别保留列表滚动位置。
- 任务目标标签移至标题下方；子任务折叠后仍可直接勾选。删除操作收进展开详情。
- 计划日期信息窄屏自适应，保留剩余时间条、必填日期和原有日期选择器。
- 目标以短色条区分，去掉重复序号；名称、描述和颜色仍为行内编辑。
- 设置重组为外观、桌面、数据：字体就地展开，主题色紧凑展示，开机启动使用开关。
- 垃圾桶、确认对话框、按钮沿用同一套字体、颜色和方角样式。
- 已有用户的字体与主题选择保留；新安装默认使用 Inter / 微软雅黑 UI 回退及松绿主题。

## 验证

`flutter analyze --no-pub`；`flutter test --no-pub`（23 项）。新增 400px / 340px 页面与行内编辑回归检查。

可选预览：`flutter test --no-pub --dart-define=CAPTURE_UI=true test/widget_test.dart --plain-name "quiet layout"`，输出到被 Git 忽略的 `build/ui-preview/`。真实字体预览在当前 Windows 开发机加载系统微软雅黑与 E 盘 Flutter 的图标字体；不将系统字体复制或分发到应用。
